## 🗣️ Målsvar att kunna utantill inför examinationen

När mappen är klar ska du kunna återge dessa med egna ord:

> **Ankarnav:** "Länkar i `nav` pekar på `id` på samma sida (`href="#hero"` kräver `id="hero"`). Klick scrollar till sektionen — som hissknappar som måste matcha våningens skylt."

> **Media query:** "En media query är CSS som bara gäller vid vissa skärmbredder. Jag anpassar t.ex. kolumner så smal vy inte krossar layouten — andra regler när kartan måste fällas ihop."

> **Ägarskap:** "AI får användas, men jag måste förstå, felsöka och försvara koden. Annars saknas ägarskap — och det är IG-risk."

## 📝 Examination

**Examination 1 (Eventsidan)** — samma sida:

- **Hero** — namn, bild/logotyp, datum, plats, kort beskrivning  
- **Schema** — **CSS Grid** (se [06-css-grid](../06-css-grid/))  
- **Highlights** — **Flexbox**  
- **Nav + footer** — ankare till sektioner; sidfot med kontakt + fiktiva sponsorer  
- **Responsivitet** — `@media`; testa viewport så layouten inte går sönder  

**README tre frågor:** semantik, arv, Flex vs Grid (motivera från er kod).  
**GitHub:** gemensamt repo, synliga commits från alla (samma dator → namn i meddelandet).  
**AI:** tillåtet — du äger varje rad.
